# Dinopage

## Description
Dinopage — free online notes app. Write your great thoughts and best ideas 💡

## Technologies
- Next.js
- Redux Toolkit
- TypeScript
- Zod
- Tailwind
- TipTap
- Floating UI

## Opportunities
- Creating notes
- Writing title and text in note
- Editing the text style
- Saving notes
- Registration and Login

## Project Web-Site
https://dinopage.com

## Installation
1. Clone the repository: git clone https://github.com/Elmir-52/dinopage-frontend.git
2. Go to the project directory: cd dinopage-frontend
2. Install the dependencies: npm install

## Using
- Build the app: npm run build
- Launch the app: npm run start
